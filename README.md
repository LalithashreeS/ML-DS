# Machine Learning Projects Using Python

## 📌 Project Overview
This repository contains multiple Machine Learning projects developed using Python and Jupyter Notebook. These projects demonstrate data preprocessing, exploratory data analysis, model training, prediction, and performance evaluation using Scikit-learn.

## 🚀 Projects Included

### 1. Iris Flower Classification
- Analyzes the Iris flower dataset.
- Uses Logistic Regression and Decision Tree algorithms.
- Performs feature scaling using StandardScaler.
- Visualizes feature relationships using Pairplot.
- Evaluates models using accuracy, precision, recall, F1-score, and confusion matrix.
- Uses PCA for decision boundary visualization.

### 2. Housing Price Prediction
- Predicts median house values.
- Uses Random Forest Regressor.
- Handles missing values using SimpleImputer.
- Applies One-Hot Encoding to categorical variables.
- Evaluates performance using RMSE and R² score.

### 3. Customer Churn Prediction
- Predicts whether customers are likely to leave a service.
- Uses Random Forest Classifier.
- Performs data cleaning and preprocessing.
- Applies categorical encoding and feature scaling.
- Evaluates the model using Accuracy, ROC-AUC, and Classification Report.
- Visualizes feature importance and confusion matrix.

### 4. Sentiment Analysis
- Analyzes customer reviews and predicts sentiment.
- Performs text preprocessing and stop-word removal.
- Uses TF-IDF for text feature extraction.
- Implements Multinomial Naive Bayes and Logistic Regression.
- Tests custom text inputs.
- Evaluates models using accuracy and classification reports.

3. Install the required libraries.
4. Update the dataset file paths in the notebook.
5. Make sure the required datasets are available.
6. Open `Wine.ipynb`.
7. Run the cells one by one.
